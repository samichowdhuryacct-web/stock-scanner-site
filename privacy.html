Privacy Policy

Last updated: October 9, 2026

Stock Scanner is a personal-use application for analyzing stock market data and sending trading alerts to its owner.

Information Accessed

The application uses Google OAuth authorization to access the Gmail API for sending alert emails. It does not request access to read or delete Gmail messages.

How Information Is Used

Gmail authorization is used solely to send automated stock trading alerts on behalf of the authorized account.

Data Storage and Sharing

OAuth credentials are stored in private application configuration and are not intentionally shared with third parties. The application does not sell personal information.

Revoking Access

The account owner can revoke Google account access through Google Account security settings.

Contact

For questions about this application, contact the application developer using the support email listed on the Google OAuth consent screen.
